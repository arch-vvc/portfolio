Call QA for voice agents

The problem

Nobody can prove a voice agent follows a client's script before go live, so QA is people listening to calls.

What it does

Paste a client SOP. Simulated callers, including Hinglish and adversarial ones, talk to the agent. A judge scores every call against the SOP. The dashboard shows the exact turn where each call went wrong.

Proof

A scripted walkthrough of 20 callers goes from 70% to 95% after one prompt fix, with one failure left visible. It runs with no API key.

Limits

Text only. There is no audio yet.
