Tender tracker

A case study. Built for a real user.

The problem

IT tenders are scattered across dozens of Indian state eProcurement portals and nobody has time to read them all.

What it does

Every day it reads the portals, keeps only IT work that fits the bidder, and emails a short digest with an Excel sheet. The company uses it, resulting in an 8 figure contract now underway.

Proof

  • 33 portals parsed, with the parsed count matching the listed total.
  • About 3,900 new open tenders a day, of which about 57 pass a keyword prefilter and go to a model.
  • It runs on free model tiers, at roughly 10,000 tokens in a day.
  • Every "IT" label must carry a quote found in the tender text.
  • 366 tests.

Rules it keeps

It never solves or works around a captcha or a login wall. Blocked portals are recorded as blocked and shown as gaps.

Scope

The repo is private because it holds a real bidder's focus, so there is no repo link here. This page is the written case study.
